Astro version 1 é a primeira versão de um projeto de assistente pessoal, nessa primeira versão, o assistente tem falas pré-definidas e tem reconhecimento de voz. As funcionalidades de Astro se resumem a pesquisas básicas no google e youtube.

Python 3.11.6

Bibliotecas

pip install speech_recognition

pip install gTTS

pip install random

pip install webbrowser

pip install pyttsx3

pip install playsound
